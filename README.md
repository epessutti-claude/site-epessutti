# Mídias do Epessutti

Branch só de mídia (vídeos e imagens dos posts), usada como link público para o Metricool.
Não faz parte do site: a Netlify publica apenas a branch `main`, então nada aqui gera deploy nem gasta créditos.

Link de cada arquivo (usar este no Metricool, serve o vídeo com o tipo certo):
`https://cdn.jsdelivr.net/gh/epessutti-claude/site-epessutti@midia/<pasta>/<arquivo>`

Obs.: o link do jsDelivr fica em cache; para trocar um vídeo, suba com um nome novo em vez de sobrescrever.
